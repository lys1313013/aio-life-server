# AIO Life 数据库表结构

本文档由 `aio-life-server/sql/1_init_table/` 目录下全部建表与变更脚本合并生成（ALTER TABLE 的 ADD/MODIFY/DROP COLUMN 已按脚本日期先后合并到对应表，同名列以后执行的脚本为准）。

统一约定：

- 数据库：`aio-life`，所有表使用 **InnoDB** 引擎，字符集 **utf8mb4 / utf8mb4_unicode_ci**
- 逻辑删除：业务表统一包含 `is_deleted` 字段（0=未删除，1=已删除），由 MyBatis Plus 全局配置处理
- ID 生成：新表 ID 使用雪花算法（`IdType.ASSIGN_ID`）在应用层生成，部分历史表为 `AUTO_INCREMENT`
- 公共字段：审计字段统一为可空的 `create_user` / `update_user`（bigint）和 `create_time` / `update_time`（datetime）；系统任务或初始化数据允许操作人为空
- 例外：`api_key_log`、`login_log`、`mail_log` 为追加型日志表，`enum_type` 为枚举定义表，不要求完整审计字段及逻辑删除字段
