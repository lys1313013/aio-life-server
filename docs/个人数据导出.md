# 个人数据导出部署与维护

更新：2026-10-28。数据导出默认开启，可通过 `AIO_LIFE_DATA_EXPORT_ENABLED=false` 显式关闭。跨端行为及实现边界见[需求与实现说明](../../docs/需求/个人数据导出需求与技术方案.md)。

## 部署准备

首次部署前完成以下准备；环境尚未就绪时可显式关闭开关，准备完成后移除关闭配置或设为 `true`，再重启应用。

1. 按[数据库初始化与验证](数据库初始化与验证.md)初始化当前全量结构和种子数据，包含导出任务、审计、一次性授权、全局控制四张表及固定控制行。
2. 使用现有 MinIO 连接，单独创建私有桶 `aio-life-user-exports`。不能复用普通文件或 CBTI 桶；该桶不能附加任何 bucket policy，访问仅通过服务端 IAM 凭据授权。服务身份需要桶存在/策略查询、列举、上传、读取、stat、删除权限。程序不会自动创建桶或修改现有桶策略。
3. 配置专用临时目录（默认系统临时目录下的 `aio-life-exports`），服务进程独占写权限，所在磁盘启用加密，至少预留并发任务所需临时空间。对象存储按部署要求配置静态加密。代码只设置单任务目录 0700，不自行管理加密密钥。
4. 确认 Redis 可用，用于核验防刷和下载互斥；MySQL 才是月额度和任务状态的来源。
5. 启动应用，未配置开关时默认开启。JSON 接口、下载接口均复用 `/api` 代理；保持 `Authorization`、`Idempotency-Key`、`X-Export-Grant` 请求头，私有桶不要配置为公开路径代理。下载路径禁用代理缓存，超时和响应缓冲按成品大小配置。
6. 使用测试账号验证核验、生成、下载、删除、月额度及审计，再向用户开放。无可用密码的账户需要先设置登录或二级密码。

关闭开关会拒绝新请求并停止下一轮领取/清理，不作为即时终止已运行任务的紧急撤权机制；停机中断由租约机制在重新启用后恢复。

## 配置

Spring 配置前缀为 `aio.life.server.data-export`。启用开关支持上述简写环境变量；其余字段可使用 Spring 标准环境变量映射或部署配置文件，不写入凭据。

| 配置项 | 默认值 | 说明 |
| --- | --- | --- |
| `enabled` | true | 默认开启；设置 `AIO_LIFE_DATA_EXPORT_ENABLED=false` 或标准配置 `aio.life.server.data-export.enabled=false` 可关闭 |
| `monthly-limit` | 5 | 允许 1–5；没有每日限制参数 |
| `batch-size` | 500 | 每批读取，最多 1000 |
| `max-concurrent` | 2 | 数据库保证的全局执行上限，最多 2 |
| `max-queued` | 100 | 含执行中的活动任务上限，最多 100 |
| `max-minutes` | 15 | 排队及执行总时限，最多 30 分钟 |
| `artifact-hours` | 24 | 成品可下载时长 |
| `max-downloads` | 20 | 单个成品最多下载尝试次数，不消耗生成额度 |
| `sheet-rows` / `workbook-rows` | 100000 / 500000 | 自动分 Sheet / 分卷阈值 |
| `max-bytes` | 524288000 | 成品最多 500 MiB |
| `max-temporary-bytes` | 2147483648 | 每任务临时目录最多 2 GiB |
| `bucket` | aio-life-user-exports | 独立私有桶 |
| `temporary-directory` | 系统临时目录/aio-life-exports | 专用工作目录 |

目录接口返回 `artifactHours` 用于界面说明，任务具体到期时间以服务端响应为准。

## 数据维护

- 新业务优先登记 `resources/export/datasets.json`；明确列、owner、父表规则、菜单、字段类型。不能从请求指定表、字段或查询表达式。
- 新表和新字段必须登记导出或排除原因；运行 `ExportDatasetRegistryTest`，再用真实 MySQL 执行全部数据集 SQL。
- 非 MySQL 数据源实现 `ExportDatasetContributor`。Neo4j 现有实现是读取区间一致性，不是全图快照。
- 本月已计次任务不得物理或逻辑删除，否则会影响额度账本；删除文件只修改文件状态并清理对象。任务和审计目前保留，不自动按 90/180 天清空。
- 清理每分钟扫描，文件逻辑撤销立即阻止下载；物理清理失败会重试。无引用对象/受限临时目录保留至少 1 小时后清理。
- 关键事务审计失败会拒绝提交；下载结束事件失败仅记录安全日志。监控相关错误及长期无终态任务，不能把只有 DOWNLOAD_STARTED 的记录解释为下载完成。

## 本地验证

后端单元测试：`mvn -Dtest=ExportPropertiesTest,ExportDatasetRegistryTest,ExportJobServiceTest,ExportSecurityTest,ExportAuthorizationTest,ExcelExportWriterTest test`。

`PersonalDataExportIntegrationTest` 会写入并清理固定测试用户及记录，只能在隔离 MySQL 测试库执行。通过 `AIO_LIFE_DB_URL`、`SPRING_DATASOURCE_USERNAME`、`AIO_LIFE_DB_PASSWORD` 指向测试实例，先执行完整建表脚本。

`ExportStorageIntegrationTest` 只有显式提供 `AIO_EXPORT_TEST_MINIO_ENDPOINT=http://127.0.0.1:<port>` 时运行；使用源码中的固定测试凭据，临时切换测试桶策略验证公开桶拒绝，因此只允许独立本机 MinIO。不要对生产实例运行这些夹具。
