# 操作和访问日志

系统管理包含管理员菜单 `/system/operation-log`、`/system/access-log`。操作日志展示用户 ID、用户名、功能点、请求地址、请求方式、请求参数、请求时间、处理时间、请求 IP、服务器 IP 和结果；访问日志保留账号、名称、IP、浏览器、登录方式、结果和操作时间。

## 部署顺序

1. 尚未建立日志表的旧库先执行 `sql/1_init_table/2026-09-22_add_sys_activity_log.sql`，仅在旧版切换前回填历史登录记录，避免新版双写后重复导入。
2. 已有日志表的旧库执行 `sql/1_init_table/2026-10-21_operation_log_request.sql` 一次，增加 5 个可空列和 1 个索引。已包含在全量结构的新库不重复执行增量。迁移不回填参数、精确请求时间、方法、耗时或服务器 IP。
3. 缺少操作日志菜单时执行 `sql/2_ini_data/2026-10-21_operation_log_menu.sql`，已纳入升级计划；新库 `2_menu.sql` 同样包含该入口。脚本只补缺失记录，不改已有配置或删除状态，仅管理员可见且仅启用 Web。访问日志菜单仍沿用原有配置。
4. 按[数据库升级验证](数据库升级验证.md)执行结构预检，再部署后端和 Web。应用不会自动执行 SQL。

## 采集范围与时间

- 访问日志保留 `/auth/login` 成功/失败及 `/auth/logout` 登出。登出前保存用户身份，失败登录只保存尝试账号；参数不采集。
- 操作日志记录已通过鉴权并到达 Controller 的 HTTP 请求，包括查询、写入、API Key 认证请求。排除会话信息、权限码、未读心跳、文件预览/下载、OPTIONS 和管理监控；拦截器拒绝、定时任务和直接调用 Service 的 MCP Tool 不属于此范围。
- 日志接口自身记录普通管理员操作，但其参数一律不保存，不嵌套记录返回正文。
- 用户与功能点保留快照。功能名优先使用服务端 `@Operation.summary`，无定义时使用 `X-Page-Path` 匹配菜单（最多缓存 60 秒），再退回“接口操作”。客户端页面来源仅用于展示，不参与授权。
- 请求 IP 使用 Servlet `remoteAddr`，可信反向代理解析由部署侧配置，不能直接信任任意 XFF。服务器 IP 读取应用实例的本机地址。
- 早期 Filter 保存 `Asia/Shanghai` 接收时间及单调时钟起点；耗时截至 Controller 返回或抛出异常，包含前置处理和参数采集，不含日志写入、后续传输和异步后台任务。`durationMs` 为 Integer 数字，0 ms 有效。历史时间回退 `createTime` 并标注“历史记录时间”。
- 结果按 `ApiResponse.code == 0` 或异常判定，不能只检查 HTTP 200。日志独立事务写入；业务回滚仍保留失败日志，日志写入失败不改变业务响应。错误日志移除异常消息，避免故障路径泄露原始数据。

## 参数白名单

只保存明确许可的绑定参数，不重读请求流，不完整序列化 DTO，不记录响应正文。上限为脱敏 JSON 32 KiB、单字符串 2000 字符、8 层和 1000 节点；请求 Content-Length 超过 64 KiB 时不采集参数。超限或解析失败统一保存 NULL，其他日志字段继续写入。

`request_params` 使用 JSON 对象，按 `path`、`query`、`body` 分组；重复查询或表单值保留数组，Long 值转换为字符串。NULL 显示“未采集”，只有确认请求无参数才保存 `{}` 并显示“无参数”。不另设采集状态字段。

默认仅允许 `/tasks/**`、`/taskDetails/**`、`/goals/**`、`/timeRecord/**`、`/anniversaryRecords/**`、`/life-footprints/**` 的 ID、分页、状态、类型、排序等安全字段。内容、备注、关键词等自由文本默认不保存。未知路由不保存参数。

密码、Token、验证码、Cookie、Authorization、API Key、签名、密钥和盐值优先于白名单剔除；嵌套对象递归脱敏。含凭据或查询串的 URL 值整体替换。认证、密码库、银行卡、第三方绑定、API Key、系统配置、身体数据、日志与 MCP 路由整体禁止参数采集。文件及其他未明确支持的对象不做完整序列化。

## 接口与筛选

仅 `admin` 可调用，并沿用日志菜单锁：

- `GET /api/system/logs/operation`
- `GET /api/system/logs/operation/{id}`：未删除的 OPERATION 详情，额外返回脱敏 `requestParams` 对象或 null。
- `GET /api/system/logs/access`
- `GET /api/system/logs/operation/export`
- `GET /api/system/logs/access/export`

共同查询参数为 `startDate`、`endDate`、`username`、`page`、`pageSize`。日期默认最近 8 个自然日，清空可查询全部时间；起止可独立省略，结束日期包含整天。page 最小 1，pageSize 为 1–100。查询和导出使用已提交筛选。

本期保留原有日期和账号筛选，不增加高级筛选。账号检索转义 `%`、`_`。操作日志按请求时间筛选，历史回退 create_time；列表按有效时间和 ID 倒序。ACCESS 保留原 create_time 语义。

响应为 `{code:0,message:null,data:{items:[],total:0}}`，ID 输出 string，耗时为 number 或 null，分页 total 遵循数字契约。列表 SQL 排除参数正文；每行参数按钮按需请求详情。没有日志编辑、删除、清空接口，也没有自动清理任务。

CSV 导出全部匹配记录，以开始时最大 ID 固定上界、按 ID 倒序每批 1000 行。操作日志导出包含 10 项信息与结果、脱敏参数；访问日志保持原列。文件带 UTF-8 BOM，转义引号与公式前缀，用户 ID 按文本导出。导出顺序与列表时间排序可能不同。

## 验证

单元和 HTTP 测试覆盖业务失败码、采集故障隔离、敏感及未知接口、嵌套脱敏、URL 凭据、大小/深度/节点限制、表单分组、管理员权限、ID 字符串与参数 JSON 契约。持久化测试使用生产 Mapper，覆盖历史时间回退、毫秒边界、筛选、分页、详情范围、导出上界和业务回滚后的独立日志提交。

Web 交互回归脚本为 `scripts/e2e/operation-log.mjs`，覆盖 10 列、0 ms、按需详情、未采集/无参数、重试、筛选与导出、已有内容及空态刷新稳定、四类宽度和深浅主题、访问日志回归。脚本使用模拟 API，不代表部署环境真实数据库联调。
