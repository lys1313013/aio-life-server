# Membership platform logos

Collected 2026-10-05. Public official website icon/apple-touch-icon links, verified publisher application icons from Apple App Store, and open-source brand icon packages only. No login session, user account image, or personal media accessed.

Use manifest.json as the canonical key/name/file/source/license map. Brand marks identify membership platforms only; no endorsement is implied. Official site assets have no identified open redistribution license. Simple Icons is CC0-1.0; LobeHub is MIT. Their licenses do not override trademark rights. Source license texts and vector/original assets are retained in sources/.

PNG files are local assets; no runtime hotlinks needed. Existing colored backgrounds in official icons are preserved. Converted SVG icons are transparent 128px PNGs with upstream brand colors; ChatGPT uses a black Blossom per the OpenAI brand guidelines.

The initial low-resolution favicons for Kugou, QQ Music, and Baidu Netdisk were replaced with verified publisher 512px Apple App Store application icons, downsampled to 128px. Their source JPGs and publisher metadata are retained. Taobao identifies the Taobao platform and can represent a Taobao 88VIP membership record; this is not the separate 88VIP mark. Alipan uses its current official site app icon. Disney+ was obtained from the public en-gb official page.
