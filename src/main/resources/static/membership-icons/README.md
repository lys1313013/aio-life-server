# Membership platform logos

Collected 2026-10-05. Public official website icon/apple-touch-icon links, verified publisher application icons from Apple App Store, and open-source brand icon packages only. No login session, user account image, or personal media accessed.

Use membership-icons.json as the canonical key/name/file/source/license map. Brand marks identify membership platforms only; no endorsement is implied. Official site assets have no identified open redistribution license. Simple Icons is CC0-1.0; LobeHub is MIT. Their licenses do not override trademark rights. Source license texts and vector/original assets are retained in sources/.

PNG files are local assets; no runtime hotlinks needed. Existing colored backgrounds in official icons are preserved. Converted SVG icons are transparent 128px PNGs with upstream brand colors; ChatGPT uses a black Blossom per the OpenAI brand guidelines.

The initial low-resolution favicons for Kugou, QQ Music, and Baidu Netdisk were replaced with verified publisher 512px Apple App Store application icons, downsampled to 128px. Their source JPGs and publisher metadata are retained. Taobao identifies the Taobao platform and can represent a Taobao 88VIP membership record; this is not the separate 88VIP mark. Alipan uses its current official site app icon. Disney+ was obtained from the public en-gb official page.

NetEase Cloud Music uses its verified publisher 512px Apple App Store application icon (app ID `590338362`, bundle ID `com.netease.cloudmusic`). A deterministic rounded-square alpha mask with radius 22% of the width is applied at the original 512px resolution before downsampling to 128px. The outside corners are transparent; the original red tile, white mark and brand colors are preserved. The PNG carries its own rounded silhouette, so clients need no brand-specific clipping. It replaces the Simple Icons monochrome mark; the original SVGs are retained for provenance, and the source JPG, mask SVG and publisher metadata are recorded in the catalog. Image-generation cutout attempts were discarded; no AI-generated artwork is used.

AI platform marks use LobeHub lobe-icons at revision `82e641b4fece9d1028a127149af9ded00df5ac0c`; the exact upstream SVGs and MIT license are retained. Each is rasterized directly without added background, frame, padding, or geometry changes. Monochrome marks use black for light theme and white for dark theme; Kimi keeps its blue accent and switches the K stroke for contrast. The `darkFile` entry is selected by `?dark=true`; colored marks retain their brand colors in both themes. GLM Coding Plan uses the Zhipu brand mark; Volcano Ark uses the Volcano Engine brand mark.

OpenCode Go uses the upstream OpenCode brand mark from the same pinned LobeHub revision, with transparent black/white PNG variants. Subscription product: https://opencode.ai/go .
