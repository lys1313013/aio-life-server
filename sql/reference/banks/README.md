# 银行字典数据来源与覆盖范围

本目录保存经过筛选的官方机构名录快照，供 `sys_dict_type.dict_type='bank'` 使用。银行卡继续通过 `bank_id → sys_dict_data.dict_code` 关联，无需新增表或字段。

## 官方来源

- 国家金融监督管理总局：[银行业金融机构法人名单（截至2025年12月末）](https://www.nfra.gov.cn/cn/view/pages/governmentDetail.html?docId=1268142&itemId=863&generaltype=1)。发布时间 2026-08-14，统计日期 2025-12-31，获取日期 2026-09-27。
- [官方 PDF 附件](https://www.nfra.gov.cn/chinese/docfile/2026/1dcdad9de86f4d9d889356bb64cb313e.pdf)，共 259 页、3619 条；附件链接通过官网页面使用的公开 JSON `https://www.nfra.gov.cn/cn/static/data/DocInfo/SelectByDocId/data_docId=1268142.json` 获取。该 JSON 是网站资源，不是承诺兼容性的开放 API。
- `nfra-2025-12-31.csv` 保存中文全称、机构编码、机构类型和 PDF 页码。元数据 JSON 保存来源 URL、PDF/CSV SHA-256、分类数量；可追溯和校验，不将 PDF 文本识别结果直接写入线上数据库。

## SQL 与兼容性

银行和菜单初始化统一执行 `sql/2_ini_data/2026-09-26_bank_card.sql`。空字典一次写入3132家银行及银行卡菜单；已有15家种子时仅补入其余3117条，已有管理员自建匹配项时实际新增数减少。无需额外的银行补全脚本。

- 初始15家继续用原 ICBC、ABC 等键值和原主键，不修改已有卡片引用。
- 新银行的 `dict_value` 为 `NFRA_` 加监管机构编码。它是本系统的来源命名空间，不是银联 BIN、联行号或微信支付编码。
- `dict_label` 去掉公司组织形式后缀；`remark` 保留完整名称、机构编码、类别、统计日期和原文页码。初始15家的监管编码对应关系保存在生成脚本与CSV中。
- 按当前字典内的键值、显示名或法人全称查重，保留已有记录的名称、排序、启停及删除状态。不会复活管理员已删除的数据，也不会改写或删除存量记录。
- 不做模糊匹配。管理员自建的非标准简称/编码需在迁移前核对；不能将不同地方的农商行按简称误合并。
- 原15家保留92626101至92626115的种子主键，其余种子主键由监管编码的 SHA-256 派生，脚本检查快照内无碰撞；与数据库主键冲突会失败，不使用 `INSERT IGNORE`、`REPLACE` 或覆盖更新。
- 在停止并发维护字典的迁移窗口运行。迁移没有实际连接目标数据库；H2测试验证插入、重复运行和已有配置保留，不能代替目标MySQL迁移检查。

离线重建（Python 3，仅标准库）：

```bash
python3 scripts/generate_bank_dictionary.py
mvn -Dtest=BankDictionarySeedTest test
```

发布新版名录时，先完整提取并检查序号连续性、编码唯一性、类别数量和原文页码，再生成新快照及增量脚本。逐项审阅更名、合并和撤销，保留历史卡片引用；不能因本期名录缺失就自动删除或停用银行。

## 可选接口与补充文档

1. [微信支付：查询支持个人业务的银行列表](https://pay.wechatpay.cn/doc/v3/partner/4012697583)
   - `GET https://api.mch.weixin.qq.com/v3/capital/capitallhh/banks/personal-banking?offset=0&limit=100`
   - 要求普通服务商资格和 APIv3 签名，按 `total_count` 分页；文档说明有4000多个银行别名，示例4446不是当前实测总量。
   - 应读取 `bank_alias` / `bank_alias_code`；不能用 `account_bank_code` 唯一标识全部银行，因为非直连银行会统一返回1099。
   - [开发指引](https://pay.wechatpay.cn/doc/v3/partner/4012160820) 在2026-06-09版本标注灰度测试、暂未开放使用。尚未用真实服务商凭据验证可调用性，不作为当前系统运行依赖。
2. [微信支付：银行类型对照表](https://pay.wechatpay.cn/doc/v3/merchant/4012076355)
   - 提供 Excel 附件和借记卡/信用卡支付编码，可用于品牌别名补充。
   - 混有钱包、卡组织、其他银行以及历史名称，必须过滤并人工映射；支付平台覆盖范围不能直接等同全国银行全集。

当前实现只将已审阅的监管名录补入本地系统字典，没有接入任何外部卡号查询，不向第三方发送用户卡号。
