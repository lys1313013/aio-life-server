# PostgreSQL 公共种子拆分证据

`seed-split.json` 记录旧 `V20261110_02__public_seed_data.sql` 的固定 SHA-256、原文件头、结构来源摘要和 11 份分类文件摘要。原聚合 SQL 不再复制保留，分类文件中 `BEGIN ORIGINAL SEED SQL` 后的片段按版本拼接，加上原文件头，必须逐字节还原原脚本。

此目录不参与 Flyway 发现，不包含业务数据或目标库连接。当前分类与执行顺序见 [SQL 入口](../../README.md)，已执行旧种子的库按[一次性拆分登记](../../../docs/数据库初始化与验证.md#已执行旧公共种子的库一次性拆分登记)处理。登记工具只在显式命令下运行，不能用于通用修复或跳过迁移。
